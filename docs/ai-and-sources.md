# AI and sources declaration (DL12)

## Summary

I used an AI assistant, Claude (Anthropic), throughout this assessment, working in a Claude project with its GitHub, Google Drive and Gmail connectors. I did not use any other AI tool.

**What Claude did:** planned the work from the brief; wrote most of the Terraform, application code, tests, pipeline workflows and scripts; wrote the documents (ADRs, design document, runbook, incident answers, load test and restore drill write ups, this declaration); drew the architecture diagram; and read my screenshots to diagnose failures.

**What I did myself:** every action in AWS, and the decisions in GitHub. Claude pushed commits and opened pull requests through its GitHub connector (listed in the log below); I reviewed and merged every pull request. I ran every `terraform plan`, `apply` and `destroy`, every AWS CLI command, the k6 load tests and the restore drill, from my own Codespace. I approved the production release gate, merged every pull request, made the decisions offered to me (single account, deleting an old IAM user, destroy timing, official AWS icons), entered every value in the AWS Pricing Calculator and took every evidence screenshot. No result in this repository was produced by the AI without being run in my account.

**How I checked it:** each change went through a pull request with `terraform plan`, Checkov, linting and tests in CI; every claim in the documents points to evidence in `docs/evidence/`; and I am studying written answers to likely review questions on every module so I can explain each line.

**No long lived credentials were shared with the AI.** Claude never had AWS access. GitHub Actions uses short lived OIDC tokens (ADR 0003).
